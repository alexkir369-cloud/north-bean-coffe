# North & Bean 2.0

A concept website for a calm neighbourhood coffee bar by the canal in Copenhagen. Beyond the menu and the café's story, it sells the order-ahead idea: order on your way, skip the morning queue and pick up your cup still warm.

- **Live site:** https://alexkir369-cloud.github.io/north-bean-coffe/
- **Design (Figma):** https://www.figma.com/design/Wy2cniCaGZG3bsb7EBxSQA/North---Bean?node-id=54-2

## Stack

React, TypeScript, Vite and Tailwind CSS.

The site is in English and Russian. Add `?lang=en` or `?lang=ru` to the URL, or use the EN / RU switch in the header. The choice is remembered. All texts for both languages are in `app/src/copy.ts`.

## Run locally

```bash
cd app
npm install
npm run dev
```

Then open http://localhost:5173/north-bean-coffe/.

## Publish

GitHub Pages serves the `main` branch from the repository root.

```bash
cd app
npm run deploy
```

`npm run deploy` builds the site and copies `app/dist` into the repository root, replacing the previous build. Commit the result and push to `main`.

After adding or replacing photos, run `npm run images` to regenerate the smaller WebP copies.

## Repository layout

- `app/` — source code
- repository root (`index.html`, `assets/`, `images/`) — the published build, generated by `npm run deploy`
- tag `v1-site` — the previous version of the site
